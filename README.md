# WoodVeda.arts — Official Flagship Showcase Website

A luxury, responsive website built for **WoodVeda.arts** to showcase signature acrylic mirror wall decor listed on Flipkart.

## 🌟 Features
- **Official Flipkart Listings**: Direct integration with Flipkart product pages for Anime Swirl Acrylic Wall Mirror (18" x 18") and Black Bonsai Shape Mirror Tree Decor.
- **Interactive Wall Placement Visualizer**: Preview products against different wall paint colors with a real-time size adjustment slider.
- **Request a Custom Design Form**: Form with drag-and-drop reference image upload delivering directly to `salesh54322@gmail.com` via FormSubmit.co.
- **Quick View Modals**: Full dimension, material, and packaging specifications popup.
- **Modern Luxury Aesthetic**: Dark obsidian mode with Playfair Display typography, gold gradients, glassmorphism, and smooth micro-animations.

## 📁 File Structure

## 🚀 How to Run Locally
Simply double-click `index.html` to open in any web browser, or serve using Python:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.
